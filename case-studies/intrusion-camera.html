CASE STUDY 02 · PFA 2026 · EDGE AI · COMPUTER VISION

Intelligent Intrusion Detection Camera

A person-detection camera running entirely on a Raspberry Pi 4 — YOLOv8n for perception, 3-level alert logic and MQTT for integration.

Raspberry Pi 4YOLOv8nOpenCVMQTTGPIO

CONTENTS

01Problem

Classical motion-based intrusion cameras drown in false alarms — any moving shadow triggers them. The project goal was a camera that detects people specifically, runs on a budget edge board, and alerts with three severity levels instead of a binary signal.

02Context

Delivered as a 2026 PFA internship. Constraints: one Raspberry Pi 4, USB camera, no GPU, low latency, and clean integration with existing device ecosystems via MQTT.

  • Edge-only inference — no cloud round-trip.
  • Alerting on three levels: detect → confirm → escalate.
  • Physical actuation through GPIO (LED / buzzer).

03Architecture

PIPELINE (ON-DEVICE)

04Methodology

  • Model: YOLOv8n — chosen for CPU-friendly inference on the Pi 4.
  • Logic: confidence thresholds mapped to 3 alert levels, debounced over time to avoid flicker.
  • Outputs: GPIO (LED / buzzer) for local actuation + MQTT topic for remote dashboards.

05Implementation

  • Python + OpenCV capture loop piped into the YOLOv8n detector.
  • Cooldown and escalation state machine for the alert levels.
  • MQTT broker publishing detection events with level and timestamp.

06Results

3-levelalert escalation on-device
Edgezero cloud dependency
MQTTclean device integration

Person-specific detection eliminated the false-alarm problem of classic motion sensors, and the 3-level logic gave operators meaningful escalation instead of a binary beep.

07Lessons learned

  • Model choice is a latency/accuracy trade — nano-scale YOLO is what makes edge feasible.
  • State machines matter more than models in alert UX: debounce, cooldown, escalation.
  • MQTT decouples the camera from its consumers — one device, many dashboards.

08Future improvements

  • Message queues and camera motion compensation for multi-camera sites.
  • Privacy-aware anonymization of frames before any off-device sync.
  • Model quantization (INT8) to push frames-per-second even higher.
