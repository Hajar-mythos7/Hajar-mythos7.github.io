CASE STUDY 04 · REAL-TIME WEB · SCADA

WebSCADA Pro

A real-time industrial supervision platform: SVG synoptic diagrams, 3-level alarms, 24-hour trends and OEE — all streamed to the browser over WebSocket at <15 ms.

ReactNode.jsSocket.ioInfluxDB

CONTENTS

01 · Problem 02 · Context 03 · Architecture 04 · Methodology 05 · Implementation 06 · Results 07 · Lessons learned 08 · Future improvements

01Problem

Industrial plant operators still live in legacy desktop SCADA — slow to update, hard to reach remotely, painful to integrate with other business systems. The goal: a browser-native supervision UI with genuinely real-time telemetry.

02Context

  • Modern web stack (React front-end, Node back-end).
  • Time-series storage for history and trends (InfluxDB).
  • Requirement: alarm management with three severity levels and an availability metric (OEE).

03Architecture

DATA PATH

04Methodology

  • Live path: telemetry pushed via WebSocket to React — no polling.
  • History path: time-bucketed queries to InfluxDB for 24-hour trends.
  • Alarms: threshold engine with 3 levels (info / warning / critical), persisted and acked.

05Implementation

  • SVG synoptic components rendered declaratively in React from an equipment model.
  • Socket.io server fanning out state deltas to all connected clients.
  • OEE computed from availability / performance / quality windows.

06Results

<15 mslive telemetry latency
24 hpersistent trends
3-levelalarm management

The WebSocket path keeps the UI effectively live, and the SVG synoptics give operators a familiar plant view without the legacy desktop runtime.

07Lessons learned

  • Delta sync (send state changes, not full frames) is what keeps latency low at scale.
  • Declarative SVG from a model beats hand-drawn screens — equipment changes stay cheap.
  • Alarms need acknowledgement workflow, not just display.

08Future improvements

  • Predictive alerts powered by the anomaly-detection methods used in the OCP monitoring work.
  • PLC-protocol-native ingest (Modbus / OPC-UA).
  • Role-based dashboards and audit trail for operators.
